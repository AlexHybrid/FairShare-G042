SQLite Database & Dynamic Migrations

Serverless SQLite Engine

Stores records locally in rental_blossoms.db. No complex server configuration required, rendering the project fully portable.

Zero-Crash Schema Migrations

Uses PRAGMA checks to inspect existing columns. Safely runs ALTER TABLE ADD COLUMN in-place if schemas change, protecting user data from deletion.

Smart Seeding Logic

Populates initial utility bills for Room A-E if launch detection finds the database empty, preventing blank-screen confusion.

database.py python 
# Schema Check & Migration in database.py
columns = [row[1] for row in cursor.execute('PRAGMA table_info(expenses)').fetchall()]

if 'payment_method' not in columns:
    cursor.execute('ALTER TABLE expenses ADD COLUMN payment_method TEXT')
    
if 'receipt_path' not in columns:
    cursor.execute('ALTER TABLE expenses ADD COLUMN receipt_path TEXT')

Auditing & JSON Export Utilities

Data Serialization (dump_data.py)

A developer utility that exports the database into a formatted JSON text file (Readable_Database.json).

Serialization: Converts SQLite Row objects into readable JSON format.
Formatting: Pretty-prints with 4-space indentation for easy auditing.
Safety: Executes within try-finally wrapper to guarantee database shutdown.
